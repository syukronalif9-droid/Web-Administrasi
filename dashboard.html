Pusat Bantuan

1. Panduan Dashboard

Aging dihitung dari Tanggal GR (Posting Date Work Days) hingga tanggal yang dipilih di filter (atau tanggal hari ini jika filter dikosongkan).

Ontime — Aging ≤ 3 hari
Late — Aging > 3 hari

2. Cara Menginput Work Days dari SAP

Pada saat Anda membuka menu Work Days di SAP, isilah parameter pencarian berikut:

Type of Data Input (Bagian Atas):
  • Pastikan Anda memilih (mencentang radio button) opsi Goods Receipt.
Bagian Item Data:
  • Material: Diisi dengan cara memencet tombol kuning (Multiple Selection) di ujung kanan kolom tersebut. Isi dengan data material yang ditarik dari data stock pada saat itu juga (copy-paste dari file stock).
  • Plant: Diisi dengan cara memencet tombol kuning (Multiple Selection) di ujung kanan kolom tersebut, lalu masukkan angka 1000 dan 2009.
  • Storage Location: Isi dengan kode lokasi penyimpanan (contoh: CEN5).
Bagian Header Data:
  • Posting Date: Isi dengan rentang tanggal transaksi yang ingin ditarik (contoh: dari tanggal 28.08.2026 ke 25.09.2026).

Setelah itu, klik tombol Execute (F8) lalu Export (Spreadsheet) datanya dalam format Excel untuk di-upload ke sistem ini.

3. Cara Menginput Framsys dari SAP

Pada saat Anda membuka menu Framsys di SAP, isilah parameter pencarian berikut:

Bagian Parameter Pencarian:
  • Material: Diisi dengan cara memencet tombol kuning (Multiple Selection) di ujung kanan kolom tersebut. Isi dengan data material yang ditarik dari data stock pada saat itu juga (copy-paste dari file stock).
  • Plant: Diisi dengan cara memencet tombol kuning (Multiple Selection) di ujung kanan kolom tersebut, lalu masukkan angka 1000 dan 2009.
  • Purchase order: Diisi dengan cara memencet tombol kuning (Multiple Selection) di ujung kanan kolom tersebut. Isi dengan data PO yang diambil dari data Work Days.
  • Posting Date: Diisi dengan cara memencet tombol kuning (Multiple Selection) di ujung kanan kolom tersebut untuk memasukkan rentang tanggal.
Bagian Display Options (Bawah):
  • Pastikan Anda memilih (mencentang) opsi Flat List.

Setelah itu, klik tombol Execute (F8) lalu Export (Spreadsheet) datanya dalam format Excel untuk di-upload ke sistem ini.

Panduan Upload

1. Master Employee (.xlsx / .csv)

Kolom wajib: Pers.No., Full Name, Employee Subgroup, Work Contract, Cost Ctr, WH Area, Location, Remarks.

*Catatan: Kolom Pers.No. & Full Name adalah kunci utama pencocokan data biodata karyawan.

2. Work Days (.xlsx / .csv)

Kolom wajib: Month, Index, Nama, Hari Kerja, Sakit, Izin, CT, CH, CK, Libur Bersama, Dispens., Alpa, Keterangan.

*Catatan: Kolom Index (nomor Pers.No) dan Nama digunakan untuk sinkronisasi data presensi bulanan. Kolom Area & Bagian otomatis di-lookup dari Master Employee.

3. Framsys (.xlsx / .csv)

Kolom wajib: KIT TK, Nama TK, Date Shift, Time In, Time Out, Durasi (Jam).

*Catatan: Data mesin absensi harian ini digunakan untuk rekap detail jam masuk, jam pulang, dan durasi kerja di slide Summary & Framsys.

Perhatian Penting

Format file sekarang didukung penuh dalam bentuk Excel (.xlsx, .xls) maupun CSV. Penulisan header kolom (termasuk huruf kapital dan titik seperti Pers.No. dan Dispens.) wajib sesuai persis dengan daftar di atas agar data dapat diproses sempurna.
